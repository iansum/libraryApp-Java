# Library Management System

A comprehensive library management system built with pure Java.

## Project Overview
This application provides a console-based interface for managing library operations including book management, member registration, and borrowing/returning books.

## Features
- 📚 Book Management (Add, Remove, Search)
- 👤 Member Management
- 📖 Borrow and Return Books
- 🔍 Search Functionality
- 📊 Transaction History
